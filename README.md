# Temuco Dulce - E-commerce CLI

Aplicación de consola en Java para la gestión de productos y ventas en "Temuco Dulce".

## Características
- **Administrador:** CRUD completo de productos (Listar, Buscar, Crear, Editar, Eliminar).
- **Usuario:** Carrito de compras, aplicación automática de descuentos y confirmación de orden.

## Reglas de Descuento
- **Descuento Automático:** Si el total base supera los $20.000, se aplica un 10% de descuento automáticamente.

## Instrucciones de ejecución
1. Asegurarse de tener instalado Java JDK.
2. Compilar los archivos: `javac *.java`
3. Ejecutar la aplicación: `java Consola`

## Ejemplo de compra
1. Ingresa como **USUARIO**.
2. Selecciona **Agregar al carrito** con el ID del producto y la cantidad.
3. Elige **Ver mi carrito** para validar los ítems.
4. Selecciona **Confirmar compra** para ver el resumen con el descuento aplicado.
